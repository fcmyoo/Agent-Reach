# 多引擎编排边界定稿（grill-me 拷问定稿）

> 定稿时间：2026-08-08 · 通过逐项拷问（Q1-Q5 + 双域确认）与用户确认 · 本文件是**唯一事实来源**，
> Codex 出方案、Hermes 路由、Claude 执行均以此为准。

---

## 0. 双域路由（最高层判断，先于一切路由）

任何任务进来，先判断是否**涉及项目代码/仓库改动**：

```
任务进来
 ├─ 用户指定引擎？ ─────────────────────→ 遵从（开发域/日常域均适用）
 ├─ 涉及项目代码/仓库改动？
 │    ├─ ✅ 开发域 ────────────────────→ 第 1~5 节三引擎协议
 │    └─ ❌ 日常域 ────────────────────→ 下表
```

| 日常域类型 | 例子 | 处理 |
|---|---|---|
| **事务型** | 查资料、总结文章、问答、整理文件、飞书/微信消息 | **Hermes 直办**（不派引擎） |
| **内容型** | 写文档/周报/邮件、PPT、Excel 整理 | **Hermes + 对应技能**（docx/xlsx/pptx…） |
| **研究型** | 深度调研、方案对比、市场分析、流程设计 | **Hermes 先干 → 干不好或用户要求再升级 Codex sol**（懒升级，与 L1 不烧 sol 同原则） |
| **自动化型** | 定时任务、监控告警、日报 | **Hermes cron/gateway**（不派引擎） |
| **编码型** | 写代码、改 bug、重构 | 转开发域 |

**引擎跨域边界**：Hermes 全域主力；Codex sol 仅开发域 L3 + 日常域研究型（懒升级）；**Claude 只在开发域 L2，日常域永不出现**（Claude 只写代码）。

---

## 1. 指派方式（Q1 → A）

- **用户显式指定优先**：用户说"让 codex 做 X"/"让 claude 做 X" → 无条件遵从，不自动改判。
- **未指定** → 按第 2/3 节规则自动路由。
- 适用于**所有任务**（编码与非编码），不因任务类型跳过用户指定。

## 2. 复杂度分层 —— gpt-5.6-sol 触发线（Q2）

| 层级 | 触发条件 | 引擎 |
|---|---|---|
| **L3 高思考** | 需要多步规划 / 架构设计 / 方案文档的任务；需要权衡取舍的疑难问题（架构选型、性能、安全） | **Codex CLI（gpt-5.6-sol）** |
| **L2 编码执行** | 有冻结方案/明确的编码任务 | **Claude Code**（只写代码，不重设计） |
| **L1 直办** | 读代码、搜资料、简单问答、简单任务（改文案、跑测试、小修、查资料） | **Hermes 直接处理，不派引擎** |

- 简单任务**禁止**动用 gpt-5.6-sol（烧钱且慢）。
- 自动路由拿不准时：**默认不升级**（走 L1/L2），除非用户指定或任务明显满足 L3 条件。

## 3. 非编码任务映射（Q3）

| 非编码任务类型 | 归属 |
|---|---|
| 写方案 / 做调研分析 / 设计流程（需要思考） | Codex sol ✅（可接非编码规划） |
| 简单问答 / 搜资料 / 读代码 / 简单整理 | Hermes 直办 |
| 非编码执行（写文档、整理数据、改配置等） | **不派 Claude**（Claude 只写代码）；由 Hermes 直办或视思考量给 Codex |

## 4. 验证方式（Q4）

- **编码任务**：自动验证优先（测试 / bash -n / git diff / test.sh），验证不过不报完成。
- **非编码任务**：以**人工检查**为准，跑顺后由用户反馈再迭代调整。

## 5. 失败兜底（Q5）

1. 引擎产出不满意 → **退回重做一次**（同一引擎，附上不满意原因）。
2. 重做仍不满意 → **人工介入**（用户直接指导/接手），不无限循环。

## 路由速查

```
任务进来
 ├─ 用户指定引擎？ ──是──> 直接指派（codex / claude / hermes），跳过自动判断
 ├─ 涉及项目代码/仓库改动？（双域判断）
 │    ├─ 否 → 日常域：事务/内容/自动化 → Hermes 直办；研究型 → Hermes 先干，不行再升级 Codex sol
 │    └─ 是 → 开发域 ↓
 ├─ L3（多步规划/架构/权衡/方案文档）──> Codex gpt-5.6-sol
 ├─ L2（编码执行，有方案或明确指令）──> Claude Code
 └─ L1（读/查/问答/小修/简单任务）──> Hermes 直办
产出不满意 ──> 同引擎重做一次 ──> 仍不满意 ──> 人工介入
```
